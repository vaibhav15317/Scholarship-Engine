Install in three steps

  1. Step 1

    Install Python

    Get Python 3.10 or newer from python.org. During setup, tick “Add Python to PATH”.

  2. Step 2

    Download and unzip

    Download SmartScholarshipEngine.zip, right-click it and choose “Extract All”. Keep the files together in one folder.

  3. Step 3

    Double-click the launcher

    Open Run_Smart_Scholarship_Engine.bat. The first run installs PySide6 (needs internet), then the app opens.

Windows says “Windows protected your PC”

This appears for new files downloaded from the internet. Click “More info”, then “Run anyway”. The launcher is a short text file, so you can open it in Notepad to see exactly what it does.

Can I use it on macOS or Linux?

Yes. Open a terminal in the unzipped folder and run python3 -m pip install -r requirements.txt, then python3 smart_scholarship_engine.py.

Is the scholarship information official?

The app ships with a starter list of schemes and links to their official portals. Matches are indicative, not a guarantee of eligibility, so always confirm deadlines and requirements on the portal before applying.
